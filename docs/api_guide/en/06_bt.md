# 6. Bluetooth BLE / Mesh

```c
#include "bt_management.h"
#include "bt_proto.h"
#include "app_coexist.h"
```

Before scans:

```c
app_coexist_before_ble_scan();
bt_management_ble_scan_start(5);
/* … done … */
app_coexist_after_ble_scan();
```

Point control: provide a non-weak `bt_management_apply_set_state(item_id, value)` that updates `hub_model` and calls `hub_ui_refresh()`. Optionally enqueue the same Modbus write as the panel ([G03](./guides/G03_ble_local.md)).
