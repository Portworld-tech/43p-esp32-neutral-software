# OEM Hub UI Kit (480×480)

自研中性智能家居**中枢**二次开发画板。视觉与组件均为本仓库原创（slate / teal 体系），**不包含、不衍生第三方客户面板设计**。

UI 与底层协议解耦：可用 RS485 / Modbus TCP / MQTT / GPIO 等驱动绑定同一套界面。

## 启动

```bash
cd lvgl-front
npx serve .
```

打开 `index.html`（需联网加载 React / Babel / 字体 CDN）。

固件侧十套 Hub 主题见 [`ui/themes/`](../ui/themes/)；选型改 [`main/app_ui_theme_select.h`](../main/app_ui_theme_select.h)（见 [`docs/UI_THEME_PACKS.md`](../docs/UI_THEME_PACKS.md)）。本目录为浏览器选型原型。

## 客户交付与运行

| 场景 | 是否可直接给客户 | 说明 |
|------|------------------|------|
| 主题选型 / 交互演示 | **可以** | 拷贝整个 `lvgl-front/`，`npx serve .` 打开即可 |
| 离线内网演示 | **有条件** | 需能访问 unpkg / Google Fonts，或改为本地托管 React·Babel·字体 |
| 量产固件 UI | **不可以直接当固件** | 本包是 Web 画板原型，需再移植到 LVGL / 绑定点表 |

**给客户运行的最低要求**
1. 交付目录：`lvgl-front/`（勿混入第三方客户 UI 资源）
2. Node 可选：`cd lvgl-front && npx serve .`，浏览器打开提示的地址
3. 演示机需联网（CDN）；防火墙环境请提前镜像依赖
4. 对外话术建议：「中性视觉与交互选型包」，勿写成「已对接总线的完整 SDK」

## 当前交互逻辑（演示级闭环）

- 设备改动 → 重算整屋功率 / 室内温湿度指标
- 情景 / 日程「执行」→ 改控件状态 + 安防 + 功率，首页同步
- 设置亮度 / 夜间模式 → 屏幕 `filter` 即时生效
- 语言切换 → 房间名中/英
- **Wi-Fi**：点热点 → 开放网直连 / 加密网弹出密码键盘 → 连接成功写入 SSID·IP
- **房间控件自定义**：房间页「编辑」→ 显示/隐藏、改名、删除、从目录添加（开关/调光/帘/空调/地暖/风扇/插座）
- 各主题快捷栏可进：情景 / 安防 / 日程 / 设置

## 设计约定

- 分辨率 480×480，触控目标宜 ≥ 44px
- 品牌仅改 `:root` CSS 变量与文案字符串
- 点表与驱动层单独对接，UI 不写死总线参数
